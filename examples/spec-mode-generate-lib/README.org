* README

Run the Lisp-RPC Go code generator with the specification in this folder:

The schema file is [[file:spec.lisprpc][spec.lisprpc]].

** Running the Generator CLI

#+begin_src shell
  # Build or run directly via go run:
  go run github.com/ccqpein/lisp-rpc-golang/cmd/lisp-rpc-golang-generator \
      -input spec.lisprpc \
      -output ./output
#+end_src

This generates a Go package under =./output/demo/= containing:
- =go.mod= (Go module definition)
- =rpc_libs.go= (Typed structs, ~ToRPCType~ methods, ~ReturnType~ methods, and map registration in ~init()~)
